MarkItDown 结构转换测试文档

这个 DOCX 用来测试标题、段落、列表、表格等结构在转换为 Markdown 时的保留情况。

# 1. 文档目标

本文件不是为了测试 OCR，而是为了测试 MarkItDown 对 **原生 Word 结构** 的识别能力。你可以观察转换结果里是否出现 Markdown 标题、列表和表格。

# 2. 核心概念

MarkItDown 更像是内容提取与结构转换工具，而不是完整的文档美化排版工具。

* 标题样式应尽量转换成 Markdown 标题
* 项目符号列表应尽量转换成 Markdown 列表
* Word 表格应尽量转换成 Markdown 表格
* 普通段落通常会保持为普通文本段落

# 3. 操作步骤

1. 准备一个带结构的 DOCX 文件
2. 使用 MarkItDown 执行转换
3. 查看输出的 .md 文件
4. 比较标题、列表和表格是否被保留

# 4. 示例表格

|  |  |  |
| --- | --- | --- |
| 结构类型 | Word 中的表现 | 期望 Markdown 输出 |
| 一级标题 | Heading 1 样式 | # 标题 |
| 二级标题 | Heading 2 样式 | ## 标题 |
| 项目符号 | List Bullet 样式 | - 条目 |
| 编号列表 | List Number 样式 | 1. 条目 |
| 表格 | 真实 Word 表格 | | 列 | 列 | |

# 5. 小结

如果这个文件转换后的 Markdown 结构明显比 PDF 或图片 OCR 更完整，说明差异主要来自源文件本身是否包含可读结构。
